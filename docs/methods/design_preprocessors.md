# Предобработка дизайна

`DesignPreprocessor` подготавливает эксперимент до итогового оценивания. Он
может строить выборку, блоки, страты, mapping или назначение treatment, но не
обязан выполнять все эти действия сразу.

| ID | Что делает | Использует target | Статус |
| --- | --- | --- | --- |
| `atomic_strata` | Оставляет все комбинации категорий отдельными стратами | pre-target доступного датасета для диагностики | baseline |
| `random_reduction` | Случайно объединяет атомарные страты | нет при transform | baseline |
| `mean_sorted_reduction` | Объединяет атомарные страты по pre-target mean | pre-target доступного датасета | baseline |
| `genetic_strata_reducer` | Оптимизирует объединение атомарных страт | только pre-target, не текущий outcome | реализован |
| `prognostic_score_block_randomization` | Формирует блоки по прогнозу и рандомизирует внутри блоков | только pre-treatment данные | кандидат |

`ab_proportional` — не метод выбора A/B-групп. Это внутренняя целевая функция
генетического алгоритма для естественного пропорционального трафика:

$$
J=\sum_g\frac{N_g}{N}S_g^2.
$$

В готовой строке `ga_strata__stratified` reducer с целью `ab_proportional`
предшествует `stratified_mean_diff`; это не ещё один алгоритм.
Режим Неймана перемещён в `legacy/neyman/` и не входит в активные R&D-прогоны.
