# Оценивание эффекта и статистические тесты

## Сопоставимые оценки среднего эффекта

| ID | Что оценивает | Смещение и условия | Статус |
| --- | --- | --- | --- |
| `welch_mean_diff` | Разность средних, ATE при рандомизации | Точечная оценка несмещённая; Welch не требует равных дисперсий | основной baseline |
| `hypex_ab` | Та же разность средних через PyPI HypEx | VarWar явно передаёт `ABTest(equal_variance=False)`, то есть Welch t-test; версия пакета берётся из `importlib.metadata` | интеграционный baseline |
| `randomized_weighted_mean_diff` | Разность нормированных ёжиковых средних | При независимых от target весах сохраняет среднее; SE и CI относятся к той же взвешенной оценке | реализован |
| `permutation_mean_diff` | Разность средних с permutation-калибровкой | Точечная оценка — обычная разность средних; p-value и CI получаются из permutation inference | реализован |
| `bootstrap_mean_diff` | Разность средних с within-arm studentized bootstrap-t | Bootstrap-t интервал и p-value из studentized нулевого распределения; отдельный estimator | реализован |
| `regression_adjustment` | Центрированная регрессионная корректировка Lin с взаимодействиями | Состоятельная оценка при рандомизации; HC2 защищает стандартную ошибку от гетероскедастичности | реализован |
| `ml_rate` | ATE после cross-fitted прогноза outcome и итоговой interacted-регрессии | Состоятельность опирается на рандомизацию, честные folds и обычные условия регулярности | реализован |
| `ml_rate__crossfit_gbm_hc2` | ML-RATE с cross-fitted gradient boosting | Как `ml_rate`; выигрывает только при нелинейном прогнозе и достаточном n | реализован |
| `lin_regression__hc2_pate` | Lin HC2 для population ATE | Требует iid-выборки когорты из целевой популяции | реализован, трек `population_ate` |
| `stratified_mean_diff` | Взвешенная сумма эффектов внутри страт | Несмещённая для ATE, заданного фиксированными весами страт | реализован |

`stratified_mean_diff` обычно меняет **реализованную точечную оценку**, а не
только стандартную ошибку и доверительный интервал: внутри каждой страты сначала
считается свой эффект, затем эффекты взвешиваются. При корректной
рандомизации математическое ожидание остаётся тем же ATE.

## Детали Lin и ML-RATE

### `regression_adjustment` (Lin)

- Ковариаты центрируются по тем строкам, где конечны и outcome, и все
  ковариаты (`valid`). Поэтому `beta_T` — Lin-оценка SATE именно
  анализируемых строк. Число отброшенных строк пишется в `n_dropped_nonfinite`.
- В диагностике есть `design_columns`, `design_rank` и `rank_deficient`.
  `lstsq` и `pinv` молча обходят коллинеарность, поэтому ранг выводится явно.
- `df_method="residual"` (по умолчанию) калибрует интервал по `t_{n-p}`.
  `df_method="bell_mccaffrey"` (только для HC2) использует степени свободы
  Bell-McCaffrey: `df = tr(DM)^2 / tr(DMDM)`, где `M = I - H`,
  `D = diag(a_i^2 / (1 - h_ii))`, а `a = X(X'X)^{-1} e_T`. Матрица `n x n`
  не строится. Опция полезна при малом n и большом K.
- `pate_correction=True` (`lin_regression__hc2_pate`) оставляет точечную
  оценку и добавляет к дисперсии `gamma' Sigma_X gamma / n`. Здесь `gamma` —
  коэффициенты при `T x (X - X-bar)`, а `Sigma_X` — выборочная ковариация
  ковариат. Это неопределённость `X-bar` как оценки среднего целевой
  популяции при iid-выборке (`mu* = X-bar`). Если когорта смещена
  (`population_shift`), оценка смещена для PATE: это сценарий провала.

### `ml_rate` и `ml_rate__crossfit_gbm_hc2`

1. Строки делятся на 5 случайных folds. Каждый fold получает собственный seed.
2. Ridge-вариант подбирает силу регуляризации на внутреннем holdout, причём
   обучающие индексы перед разбиением перемешиваются RNG fold'а. Хвостовой
   holdout на упорядоченном frame не был бы случайным.
3. GBM-вариант обучает `HistGradientBoostingRegressor` на всех строках чужих
   folds, без treatment. Гиперпараметры фиксированы: `max_iter=100`,
   `learning_rate=0.08`, `max_depth=3`, `max_leaf_nodes=8`,
   `min_samples_leaf=20`, `l2_regularization=1.0`. Early stopping выключен,
   `random_state` равен seed fold'а. Категориальные ковариаты можно включить
   через `include_categorical=True`; в реестре это выключено ради времени.
4. Финальная стадия: `Y ~ 1 + T + (g - mean g) + T (g - mean g)` с HC2 и
   `df = n - 4`.

Малый MC (R = 300, H0, общие реализации):

| Мир | Lin RMSE | GBM RMSE | MSE GBM / Lin | Coverage Lin / GBM |
| --- | --- | --- | --- | --- |
| `nonlinear_panel` (n = 2000) | 0.0279 | 0.0256 | 0.84 (парный z = −3.0) | 0.940 / 0.947 |
| `gaussian_r2_04_n200` | 0.1098 | 0.1177 | 1.15 (парный z = +2.5) | 0.940 / 0.963 |

В линейном мире с малым n GBM проигрывает Lin. Одна оценка GBM при n = 2000
занимает около 0.5 с на двух потоках, примерно в 30 раз дольше ridge.

## Специализированные оценки

| ID | Цель | Почему не ставится в общую гонку ATE | Смещение и ограничения |
| --- | --- | --- | --- |
| `ratio_delta` | Разность отношений средних | Требует numerator/denominator и имеет собственную delta-инференцию | Отношение средних имеет малое конечновыборочное смещение; состоятельно вдали от нулевого знаменателя |
| `nearest_neighbor_matching` | Симметричный nearest-neighbor ATE в активной RCT-гонке; ATT остаётся отдельным режимом | В RCT matching используется как альтернативный способ построения пар, а не как замена рандомизации | Смещение зависит от overlap и размерности; стандартная ошибка учитывает не всю неопределённость выбора пар |
| `wald_late` | LATE для compliers | Нужны instrument и фактически полученный treatment | Ratio-оценка смещена в конечной выборке; состоятельна только при IV-допущениях и сильной first stage |
| `variance_weighted_stratified` | Эффект с precision-весами страт | Веса могут изменить целевую популяцию | Не является общей несмещённой ATE-оценкой при неоднородном эффекте |
| `calibration_reweighting` | Эффект в целевой популяции | Нужны внешние population totals | Заглушка; без totals это уже другой метод балансировки |
| `optimal_transport_matching` | ATE через симметричный optimal-transport matching | В активной гонке фиксируются treated/control и симметричный ATE; observational-применимость только потенциальная | Регуляризация и транспортный план могут менять конечновыборочные свойства |

Локальный `nearest_neighbor_matching` стандартизует числовые признаки и для
каждого treated ищет одного ближайшего control с возвращением. `hypex_matcher`
не является вторым готовым алгоритмом: это пока профиль будущей интеграции с
более широким matching API HypEx. До фиксации расстояния, replacement, estimand
и inference он не участвует в гонках.

## Статистические тесты

| ID | Нулевая гипотеза | Возвращает оценку ATE | Статус |
| --- | --- | --- | --- |
| `ks_test` | Распределения одинаковы | нет | реализован |
| `approx_ks_fast` | Приближённый KS-критерий по гистограмме | нет | реализован |
| `energy_test` | Распределения одинаковы | нет | реализован |
| `randomized_t_test` | Средние не различаются для hedgehog-статистики | нет согласованного ATE; поля effect/CI в общем API вспомогательны | реализован для R&D |
| `permutation_mean_test` | Assignment не связан с разностью средних | нет; основной результат — randomization p-value | реализован |
| `anti_nuclear_ks_test` | Tie-aware версия проверки распределений | нет | кандидат R&D |

Для `anti_nuclear_ks_test` зафиксировано направление: совпадающие значения
размыкаются treatment-blind способом на малом интервале, после чего p-value
калибруется перестановками. Обычный непрерывный KS p-value нельзя механически
считать точным после произвольного jitter. Детерминированная сетка допустима
только если порядок точек не использует treatment.

## Выведенные из активного сравнения

| ID | Причина |
| --- | --- |
| `pooled_mean_diff` | Точечная оценка совпадает с Welch, а pooled SE дополнительно требует равных дисперсий |
| `trimmed_mean_diff` | Групповое trimming меняет целевую метрику и дублирует идею трансформации |
| `winsorized_mean_diff` | Заменён композицией `winsorized` → базовый estimator |
| `optimal_transport_check` | Нет самостоятельной статистики или правила решения |
