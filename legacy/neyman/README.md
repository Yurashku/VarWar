# Архив режима Неймана

Этот каталог содержит снятый с активного R&D-контура прототип целочисленной
аллокации Неймана. Код сохранён для истории и возможного возврата к постановке,
но не импортируется пакетом `varwar`, не участвует в гонках и не поддерживается
автоматическими тестами.

Причина архивации: текущая стадия R&D сравнивает pipelines на полном доступном
трафике. Нейман решает другую задачу: распределяет заранее ограниченный общий
sample budget между стратами. Смешивать эти режимы в одной ranking-таблице
некорректно.

Формула непрерывного решения:

\[
n_g \propto N_g S_g,
\]

где `N_g` — размер страты, а `S_g` — историческое стандартное отклонение.
Архивный код дополнительно учитывает нижние границы, ёмкость страт и точную
целочисленную сумму allocation.
